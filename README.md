# 掘金自动签到浏览器插件

掘金每日自动签到与免费抽奖的 Chrome 扩展（Manifest V3，原生 JavaScript，无需构建）。

## 功能

- 每日定时签到，支持过点补签与浏览器启动补签
- 签到成功后自动使用当天免费抽奖次数；无免费次数时跳过，不消耗矿石
- 弹窗和设置页可手动签到、手动抽奖
- 签到日历、抽奖日历、连续 / 本月 / 累计签到天数、当前矿石
- 签到与抽奖记录可通过 Chrome / Edge 账号跨设备同步
- 可选 GitHub Actions 云端签到，电脑关机也不漏签（插件只读结果）
- 网页、其他设备或云端已签过时自动识别，不会重复签到

## 安装

1. 打开 `chrome://extensions`，开启「开发者模式」
2. 点「加载已解压的扩展程序」，选择本项目目录
3. 打开 juejin.cn 登录，点击插件图标，点「立即签到」

> 扩展 ID 由 `manifest.json` 的 `key` 固定，跨设备同步依赖它。签名私钥不要放在扩展目录内，否则会出现密钥文件提示。

## 使用

**弹窗**：签到状态、四项统计（连续 / 本月 / 累计 / 当前矿石）、当天抽奖结果；提供立即签到、立即抽奖、打开掘金。

**设置页**：自动签到开关与时间、自动抽奖、通知开关、重试次数、页面加载超时；签到日历、签到历史、抽奖日历、跨设备同步。

**自动签到规则**：

- 每天到点自动签到，成功后自动抽奖
- 过点未签时每 30 分钟补签，签上后停止
- 浏览器启动时若已过点且未签，立即补签

**跨设备同步**：设置页开启后，签到与抽奖记录写入 `chrome.storage.sync`。两台设备需登录同一 Chrome / Edge 账号并开启浏览器同步，日期按北京时间归属。

**云端签到（可选）**：`.github/workflows/checkin.yml` 每天北京时间 04:00 运行，需在自有仓库配置 `JUEJIN_COOKIE` Secret。插件在设置页填写 `owner/repo` 并开启「读取云端结果」后只读拉取，不需要 Token。

## 开发与测试

```bash
npm test                    # 签到验证链耗时
npm run test:lottery        # 抽奖门禁
npm run test:cloud-lottery  # 云端抽奖
npm run test:sync           # 跨设备同步
npm run test:missed         # 过点补签巡查
npm run test:date           # UTC+8 日期归属
npm run test:stats          # 连续 / 累计天数
```

真机端到端：`npm install && npx playwright install chromium && node e2e-checkin.js`。

修改 `background.js` 后需在 `chrome://extensions` 重新加载扩展并重启 Service Worker。

## 常见问题

- **没有自动签到**：确认自动签到开关已开、浏览器正在运行、已登录掘金。
- **签到成功但没抽奖**：检查「自动抽奖」开关；当天免费次数已用完时不会抽奖。
- **抽奖日历没有网页抽的奖**：掘金未开放个人抽奖记录接口，插件只记录自己抽的奖。
- **另一台电脑看不到同步记录**：确认同一浏览器账号、扩展 ID 一致、同步开关已开启。
- **签到日历只能看本月**：掘金接口只返回当前区间，属服务端限制。
