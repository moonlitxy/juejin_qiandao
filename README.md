# 掘金自动签到浏览器插件

一个用于自动完成掘金技术博客网站每日签到的Chrome浏览器扩展。

## 功能特性

✅ **自动签到**: 每天定时自动执行签到操作
✅ **手动签到**: 支持随时手动触发签到
✅ **状态通知**: 签到成功/失败的桌面通知
✅ **签到记录**: 保存最近的签到历史
✅ **统计信息**: 显示连续签到天数和本月签到天数
✅ **自定义设置**: 可配置签到时间、通知偏好等

## 安装方法

### 1. 准备图标文件

在项目根目录下创建 `icons` 文件夹，并添加以下三个尺寸的图标：
- `icon16.png` (16x16 像素)
- `icon48.png` (48x48 像素)
- `icon128.png` (128x128 像素)

**可以使用以下在线工具生成图标：**
- [Favicon Generator](https://www.favicon-generator.org/)
- [IconKitchen](https://icon.kitchen/)
- 或者使用任何图片编辑软件创建PNG格式的图标

### 2. 加载到Chrome浏览器

1. 打开Chrome浏览器
2. 在地址栏输入 `chrome://extensions/`
3. 启用右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本项目所在的文件夹
6. 插件安装完成！

## 使用说明

### 首次使用

1. 点击浏览器工具栏中的插件图标
2. 确保已登录掘金账号（在掘金网站手动登录一次）
3. 插件会自动保存你的登录状态
4. 点击"立即签到"测试签到功能

### 设置定时签到

1. 点击插件图标打开弹出窗口
2. 在"快速设置"区域：
   - 开启"自动签到"开关
   - 选择每天的签到时间（默认为09:00）
3. 或点击"⚙️ 设置"进入详细设置页面

### 查看签到记录

1. 打开设置页面（点击插件图标中的"设置"按钮）
2. 在"签到历史"区域查看最近30天的签到记录
3. 可以清空历史记录或查看详细的签到信息

## 技术实现

### 签到机制

插件使用多种策略来执行签到：

1. **DOM操作**: 通过分析掘金页面的DOM结构，找到签到按钮并模拟点击
2. **多重选择器**: 使用多种CSS选择器策略，提高找到签到按钮的成功率
3. **状态检测**: 检查用户登录状态和签到状态，避免重复签到
4. **错误处理**: 完善的错误处理和重试机制

### 定时任务

使用Chrome Extension的Alarms API实现定时签到：
- 支持自定义签到时间
- 自动计算下一次执行时间
- 处理跨日期的定时任务

### 数据存储

使用Chrome Storage API存储：
- 用户配置（签到时间、通知设置等）
- 签到历史记录（最近30天）
- 连续签到统计

## 注意事项

1. **登录状态**: 首次使用需要在掘金网站登录，插件会使用浏览器保存的登录状态
2. **网络连接**: 需要确保网络连接正常，否则签到可能失败
3. **页面变化**: 如果掘金网站更新页面结构，可能需要更新content.js中的选择器
4. **浏览器限制**: 某些浏览器可能需要额外的权限配置

## 常见问题

### Q: 签到失败怎么办？
A: 请确保：
- 已登录掘金账号
- 网络连接正常
- 浏览器允许插件显示通知
- 尝试手动签到查看错误信息

### Q: 为什么没有自动签到？
A: 检查：
- 是否开启了自动签到开关
- 设置的签到时间是否已到
- 浏览器是否正在运行（Chrome需要运行才能触发定时任务）

### Q: 可以修改签到逻辑吗？
A: 可以！编辑 `content.js` 文件中的签到逻辑，根据需要调整选择器和策略。

## 开发与调试

### 调试技巧

1. **查看后台日志**:
   - 进入 `chrome://extensions/`
   - 找到本插件，点击"Service Worker"查看后台日志

2. **调试content script**:
   - 打开掘金网站
   - 按F12打开开发者工具
   - 在Console中查看签到脚本日志

3. **重新加载插件**:
   - 在 `chrome://extensions/` 页面点击刷新按钮
   - 修改代码后需要重新加载才能生效

### 自定义开发

如果需要添加新功能，主要修改以下文件：
- `manifest.json`: 添加权限和配置
- `background.js`: 添加后台逻辑
- `content.js`: 修改签到策略
- `popup.html/js/css`: 修改用户界面
