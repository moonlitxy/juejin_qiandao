## 🔧 开发资源

### 加载和调试
1. 打开 `chrome://extensions/`
2. 启用"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择本项目文件夹

### 查看日志
- **后台日志**: 在 `chrome://extensions/` 页面点击"Service Worker"
- **页面脚本日志**: 打开掘金网站并按 F12

### 重新加载
修改代码后，在 `chrome://extensions/` 页面点击刷新按钮
